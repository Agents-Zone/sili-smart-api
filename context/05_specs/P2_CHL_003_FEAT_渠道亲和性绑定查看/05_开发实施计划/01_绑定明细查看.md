# 渠道亲和性绑定查看 实现计划

> **目标：** 为根管理员提供当前有效渠道亲和性缓存的渠道与令牌聚合明细，并在设置页通过缓存条目数量打开只读弹窗。
> **架构：** 后端在现有 HybridCache 上生成一次读取快照，按 token_id 解析缓存键，批量查询渠道与令牌后在内存中去重、聚合和排序。Controller 复用 option 路由组的 RootAuth 和统一响应结构。前端扩展现有渠道亲和性设置模块，使用 API 类型、弹窗状态和可访问的可点击入口展示加载、数据、空数据与错误状态。
> **技术栈：** Go、Gin、GORM、cachex.HybridCache、React 19、TypeScript、现有 api 客户端、i18next、Vitest/React Testing Library。

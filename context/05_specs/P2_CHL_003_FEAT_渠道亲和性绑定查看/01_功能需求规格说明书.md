# 渠道亲和性绑定查看 功能需求规格说明书

## 文档信息

- 基线 Feature：无
- 变更组：无
- 变更根节点：无
- 历史基线链：无

## 1. 概述

### 1.1 功能背景

渠道亲和性设置页当前仅展示缓存条目数量。根管理员无法确认缓存条目实际绑定的渠道和令牌，排查令牌亲和性、渠道复用及绑定异常时缺少明细依据。

### 1.2 本功能业务目标

1. 根管理员点击缓存条目数量后，可以查看当前有效的渠道亲和性绑定。
2. 明细按渠道聚合展示渠道名称及其绑定令牌名称。
3. 一个渠道绑定多个令牌时，在同一渠道行内展示多个令牌，避免重复渠道行。

### 1.3 功能范围

本 Feature 只提供缓存绑定关系的只读查看，不修改缓存绑定、不修改渠道、不修改令牌，也不新增筛选、分页、导出和解绑操作。

## 2. 角色与权限矩阵

### 2.1 数据权限

| 角色 | 数据范围 | 说明 |
|---|---|---|
| 根管理员 | 全部有效渠道亲和性缓存条目 | 可查看系统当前缓存中的渠道和令牌绑定 |
| 其他角色 | 无 | 不返回绑定明细 |

### 2.2 页面访问权限

| 页面名称 | 可访问角色 | 可操作角色 | 字段级权限 |
|---|---|---|---|
| 渠道亲和性绑定明细弹窗 | 根管理员 | 根管理员 | 只读；渠道名称、令牌名称可见 |

权限由现有 option 路由根管理员认证统一控制。页面不提供修改权限。

## 3. 页面与功能总览

### 3.1 页面清单

| 序号 | 页面名称 | 页面形式 | 职责说明 | 包含功能 |
|---|---|---|---|---|
| 1 | 渠道亲和性设置 | 现有设置页内嵌入口 | 展示缓存统计并提供绑定明细入口 | 点击缓存条目数量 |
| 2 | 渠道亲和性绑定明细 | 弹窗对话框 | 展示渠道与令牌绑定关系 | 加载、展示、关闭 |

### 3.2 页面跳转流程

```text
渠道亲和性设置 → 点击缓存条目数量 → 渠道亲和性绑定明细弹窗 → 点击关闭 → 返回设置页
```

1. 设置页完成缓存统计加载后，缓存条目数量以可点击文本显示。
2. 点击数量后打开弹窗并请求绑定明细接口 `GET /api/option/channel_affinity_bindings`。
3. 请求期间显示加载状态，请求完成后显示绑定列表或空状态。
4. 用户关闭弹窗后回到设置页，设置项和缓存统计保持原状态。

## 4. 页面功能详细说明

### 4.1 页面一：渠道亲和性设置入口

#### 4.1.1 页面概述

页面形式为现有系统设置页。页面保留原有缓存刷新、清理和规则配置功能，本 Feature 仅增加缓存条目数量的明细查看入口。

#### 4.1.2 涉及字段

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 业务含义 |
|---|---|---|---|---|
| 缓存条目数量 | 数字、可点击文本 | `GET /api/option/channel_affinity_cache` | 页面加载或刷新统计后 | 当前缓存中的亲和性条目总数 |
| 缓存容量 | 数字 | `GET /api/option/channel_affinity_cache` | 页面加载或刷新统计后 | 当前缓存容量显示值；Redis 模式下按现有逻辑显示 0 |

#### 4.1.3 功能与按钮

- **查看渠道绑定明细**
  - 触发按钮：缓存条目数量
  - 按钮级别：字段级
  - 按钮位置：缓存统计文本区域
  - 触发方式：点击数量
  - 权限要求：根管理员
  - 加载状态：打开弹窗后显示明细加载状态
  - 功能说明：打开渠道亲和性绑定明细弹窗并加载当前绑定数据。

#### 4.1.4 业务规则

- 缓存条目数量为 0 时仍可点击，弹窗显示空状态。
- 入口只触发查看，不改变缓存条目和现有设置。

#### 4.1.5 交互逻辑

- 数字使用可识别的可点击样式，并提供可访问名称。
- 点击后弹窗打开；接口返回前显示加载中。
- 弹窗关闭后不重置或修改设置页中的缓存统计。

### 4.2 页面二：渠道亲和性绑定明细弹窗

#### 4.2.1 页面概述

页面形式为模态弹窗。弹窗以渠道为行单位，每行展示渠道名称和该渠道的令牌绑定列表，具体聚合、排序和展示格式遵循第 4.2.4 节。弹窗只读，不提供编辑、删除、解绑和导出操作。

#### 4.2.2 涉及字段

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 校验规则 | 默认值 | 业务含义 |
|---|---|---|---|---|---|---|
| 渠道名称 | 只读文本 | 渠道模型 | 弹窗接口返回时 | 有值时展示；无值按空值规则显示 `-` | `-` | 绑定关系对应的渠道名称 |
| 令牌绑定列表 | 只读多行文本列表 | 令牌模型、亲和性缓存键 | 弹窗接口返回时 | 同一渠道内按 token_id 去重；每条记录单独占一行 | 空列表 | 按 `令牌名称（令牌 ID）` 格式展示，例如 `生产令牌（101）`；令牌名称为空时显示 `-（101）` |

#### 4.2.3 功能与按钮

- **关闭明细弹窗**
  - 触发按钮：弹窗关闭按钮
  - 按钮级别：页面级
  - 按钮位置：弹窗标题栏或底部
  - 触发方式：点击
  - 权限要求：根管理员
  - 加载状态：无
  - 功能说明：关闭弹窗并返回渠道亲和性设置页。

#### 4.2.4 业务规则

1. 只读取使用 `token_id` 作为亲和性键源且在读取时未过期的缓存条目。Redis 已配置时以 Redis 为准，否则以进程内缓存为准；不合并两个缓存来源的重复数据。
2. 缓存条目关联的渠道或令牌不存在时，忽略该条目，不生成无法识别的绑定行。
3. 一个渠道只返回一行；同一渠道的多个令牌聚合在令牌绑定列表中。
4. 同一渠道内令牌按 token_id 升序排列，渠道按渠道名称升序排列。缓存键必须解析出 token_id，缓存值提供渠道 ID；无法解析 token_id、渠道 ID 非法或关联模型不存在时按第 2、3 条处理。
5. 令牌名称为空时，按 `-（令牌 ID）` 格式显示，保留令牌 ID 作为可识别兜底值。

#### 4.2.5 交互逻辑

- 加载状态显示加载中提示。
- 没有有效绑定时显示空状态提示。
- 接口请求失败时显示错误提示，用户可关闭弹窗后重新点击入口重试。
- 令牌绑定列表的逐行格式、渠道聚合和排序遵循第 4.2.4 节。

#### 4.2.6 权限要求

本页面权限参见第 2 章，仅根管理员可访问。页面无特殊字段级权限差异。

#### 4.2.7 页面 ASCII 示意

```text
+------------------------------------------------------+
| 渠道亲和性绑定明细                              [X] |
+------------------------------------------------------+
| 渠道名称              | 令牌绑定列表                 |
|-----------------------|------------------------------|
| 主渠道                | 生产令牌（101）              |
|                       | 备用令牌（102）              |
|-----------------------|------------------------------|
| 海外渠道              | 海外生产（203）              |
+------------------------------------------------------+
|                                               [关闭] |
+------------------------------------------------------+
```

同一渠道的多个令牌在令牌绑定列表中逐行展示，渠道名称只在该渠道的首行显示；具体展示规则遵循第 4.2.4 节。

## 6. 数据状态定义

绑定明细按普通只读列表处理，仅定义列表加载、列表展示、空列表和加载失败四种状态：

| 状态 | 页面表现 |
|---|---|
| 加载中 | 弹窗内显示加载提示 |
| 有数据 | 按渠道展示令牌绑定列表 |
| 无数据 | 弹窗内显示空状态提示 |
| 加载失败 | 弹窗内显示错误提示，关闭后可重新打开加载 |

## 7. 集成和依赖

| 依赖模块 | 依赖方向 | 数据类型 | 用途 |
|---|---|---|---|
| 渠道亲和性缓存服务 | 本 Feature 主动引用 | 缓存键、渠道 ID | 获取有效缓存绑定 |
| 渠道模型 | 本 Feature 主动引用 | 渠道 ID、渠道名称 | 展示渠道名称 |
| 令牌模型 | 本 Feature 主动引用 | token_id、令牌名称 | 展示令牌名称 |
| 系统设置页权限 | 本 Feature 被其权限约束 | 根管理员身份 | 限制接口和页面访问 |

本 Feature 无外部系统依赖、无数据库结构变更、无新增定时任务。

### 7.1 绑定明细接口契约

绑定明细接口为 `GET /api/option/channel_affinity_bindings`，仅根管理员可访问。接口成功时返回统一响应结构，`data` 为渠道聚合数组：

```json
{
  "success": true,
  "message": "",
  "data": [
    {
      "channel_id": 1,
      "channel_name": "主渠道",
      "tokens": [
        { "token_id": 101, "token_name": "生产令牌" }
      ]
    }
  ]
}
```

接口在无有效绑定时返回空数组。非根管理员访问返回无权限错误，不返回绑定数据；缓存读取或模型查询失败时返回错误响应，页面显示第 4.2.5 节定义的错误提示。

## 8. 附录

### 8.1 验收标准

1. 根管理员可以在渠道亲和性设置页看到可点击的缓存条目数量。
2. 点击数量后可以打开绑定明细弹窗。
3. 弹窗展示渠道名称和对应令牌名称。
4. 一个渠道绑定多个令牌时只显示一个渠道行，并按第 4.2.4 节规则在令牌绑定列表中逐行展示。
5. 渠道和令牌排序符合第 4.2.4 节规则。
6. 无有效绑定时显示空状态，接口失败时显示错误提示。
7. 非根管理员无法通过接口获取绑定明细。

### 8.2 术语说明

| 术语 | 说明 |
|---|---|
| 渠道亲和性缓存 | 根据请求中的亲和性键复用上次成功渠道的内存或 Redis 缓存 |
| token_id | 系统令牌记录的唯一 ID |
| 绑定 | 一个亲和性键当前指向一个渠道的关系 |

### 8.3 通用需求与偏离记录

通用需求参见 [项目通用需求](../01_通用需求.md)。

本 Feature 无需分页、搜索、编辑、删除、导入或导出。弹窗采用只读查看场景，不适用通用需求中的表单提交和数据修改 loading 规则。空值、加载、错误和弹窗关闭行为按本规格第 4.2.5 节定义。

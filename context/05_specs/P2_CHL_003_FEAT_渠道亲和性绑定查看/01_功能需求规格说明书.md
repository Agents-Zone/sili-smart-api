# 渠道亲和性绑定查看 功能需求规格说明书

## 文档信息

- 基线 Feature：无
- 变更组：无
- 变更根节点：无
- 历史基线链：无

## 1. 概述

### 1.1 功能背景

渠道亲和性设置页当前仅展示缓存条目数量。根管理员无法确认缓存条目实际绑定的渠道和令牌，排查令牌亲和性、渠道复用及绑定异常时缺少明细依据。

### 1.2 本功能业务目标

1. 根管理员点击缓存条目数量后，可以查看当前有效的渠道亲和性绑定。
2. 明细按渠道聚合展示渠道名称及其绑定令牌名称，绑定含模型维度的展示所属模型，含分组维度的展示所属分组。
3. 一个渠道绑定多个令牌时，在同一渠道行内展示多个令牌，避免重复渠道行；同一令牌在不同模型/分组上下文的绑定为独立条目。
4. 根管理员可以在明细列表中按单条绑定清除，即只解除某个令牌在某个模型上下文对某个渠道的亲和。

### 1.3 功能范围

本 Feature 提供缓存绑定关系的查看与单条绑定清除操作，不修改渠道、令牌和规则配置，不提供按渠道批量解绑、筛选、分页和导出操作。全量清空与按规则清空沿用渠道亲和性设置页既有能力。

权限由现有 option 路由根管理员认证统一控制。页面不提供修改权限。

## 3. 页面与功能总览

### 3.1 页面清单

| 序号 | 页面名称 | 页面形式 | 职责说明 | 包含功能 |
|---|---|---|---|---|
| 1 | 渠道亲和性设置 | 现有设置页内嵌入口 | 展示缓存统计并提供绑定明细入口 | 点击缓存条目数量 |
| 2 | 渠道亲和性绑定明细 | 弹窗对话框 | 展示渠道与令牌绑定关系 | 加载、展示、单条绑定清除、关闭 |

### 3.2 页面跳转流程

```text
渠道亲和性设置 → 点击缓存条目数量 → 渠道亲和性绑定明细弹窗 → 点击关闭 → 返回设置页
渠道亲和性绑定明细弹窗 → 点击绑定行清除按钮 → 确认弹窗 → 确认/取消 → 返回明细弹窗
```

1. 设置页完成缓存统计加载后，缓存条目数量以可点击文本显示。
2. 点击数量后打开弹窗并请求绑定明细接口 `GET /api/option/channel_affinity_bindings`。
3. 请求期间显示加载状态，请求完成后显示绑定列表或空状态。
4. 点击绑定行的清除按钮后弹出确认弹窗；确认后调用单条删除接口并刷新明细列表与设置页缓存统计，取消后返回明细弹窗。
5. 用户关闭弹窗后回到设置页，设置项保持原状态，缓存统计按清除结果更新。

## 4. 页面功能详细说明

### 4.1 页面一：渠道亲和性设置入口

#### 4.1.1 页面概述

页面形式为现有系统设置页。页面保留原有缓存刷新、清理和规则配置功能，本 Feature 仅增加缓存条目数量的明细查看入口。

#### 4.1.2 涉及字段

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 业务含义 |
|---|---|---|---|---|
| 缓存条目数量 | 数字、可点击文本 | `GET /api/option/channel_affinity_cache` | 页面加载或刷新统计后 | 当前缓存中的亲和性条目总数 |
| 缓存容量 | 数字 | `GET /api/option/channel_affinity_cache` | 页面加载或刷新统计后 | 当前缓存容量显示值；Redis 模式下按现有逻辑显示 0 |

#### 4.1.3 功能与按钮

- **查看渠道绑定明细**
  - 触发按钮：缓存条目数量
  - 按钮级别：字段级
  - 按钮位置：缓存统计文本区域
  - 触发方式：点击数量
  - 权限要求：根管理员
  - 加载状态：打开弹窗后显示明细加载状态
  - 功能说明：打开渠道亲和性绑定明细弹窗并加载当前绑定数据。

#### 4.1.4 业务规则

- 缓存条目数量为 0 时仍可点击，弹窗显示空状态。
- 入口只触发查看，不改变缓存条目和现有设置。

#### 4.1.5 交互逻辑

- 数字使用可识别的可点击样式，并提供可访问名称。
- 点击后弹窗打开；接口返回前显示加载中。
- 弹窗内单条绑定清除成功后，设置页缓存统计随之刷新；未发生清除时统计保持原状态。

### 4.2 页面二：渠道亲和性绑定明细弹窗

#### 4.2.1 页面概述

页面形式为模态弹窗。弹窗以渠道为行单位，每行展示渠道名称和该渠道的令牌绑定列表；每条绑定独占一行，行内含令牌信息与清除按钮，绑定含模型维度时在行内展示所属模型，具体聚合、排序和展示格式遵循第 4.2.4 节。弹窗不提供编辑、导出和按渠道批量解绑操作。

#### 4.2.2 涉及字段

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 校验规则 | 默认值 | 业务含义 |
|---|---|---|---|---|---|---|
| 渠道名称 | 只读文本 | 渠道模型 | 弹窗接口返回时 | 有值时展示；无值按空值规则显示 `-` | `-` | 绑定关系对应的渠道名称 |
| 令牌绑定列表 | 只读多行文本列表 | 令牌模型、亲和性缓存键 | 弹窗接口返回时 | 每个缓存键一条记录、单独占一行；按 `令牌名称（令牌 ID） · 模型名 · 分组名` 格式展示，模型名、分组名仅在规则启用对应维度时追加 | 空列表 | 令牌与渠道的亲和绑定明细，例如 `生产令牌（101） · gpt-4`、`生产令牌（101） · gpt-4 · vip`；令牌名称为空时显示 `-（101）` |
| 操作 | 按钮列 | 前端本地 | 弹窗接口返回时 | 每条绑定行一个清除按钮 | 无 | 单条解除该令牌在该模型上下文对渠道的亲和 |

#### 4.2.3 功能与按钮

- **清除该绑定**
  - 触发按钮：绑定行内的清除按钮
  - 按钮级别：行级
  - 按钮位置：令牌绑定列表每行末尾
  - 触发方式：点击
  - 权限要求：根管理员
  - 加载状态：确认弹窗的确认按钮在请求期间禁用
  - 功能说明：弹出确认弹窗，展示令牌名称、令牌 ID、模型、分组与渠道（模型、分组仅在规则启用对应维度时出现）；确认后调用 `DELETE /api/option/channel_affinity_bindings?key_suffix={键后缀}`，仅删除该条绑定（含正向缓存、反向占用索引与最近绑定记录），同令牌其他模型、同渠道其他令牌的绑定保持不变；成功后刷新明细列表并同步设置页缓存统计，失败时提示错误且列表不变。
- **关闭明细弹窗**
  - 触发按钮：弹窗关闭按钮
  - 按钮级别：页面级
  - 按钮位置：弹窗标题栏或底部
  - 触发方式：点击
  - 权限要求：根管理员
  - 加载状态：无
  - 功能说明：关闭弹窗并返回渠道亲和性设置页。

#### 4.2.4 业务规则

1. 只读取使用 `context_int` 类型且键名为 `token_id` 的亲和性键源，并且在读取时未过期的缓存条目。Redis 已配置时以 Redis 为准，否则以进程内缓存为准；不合并两个缓存来源的重复数据。
2. 缓存条目关联的渠道或令牌不存在时，忽略该条目，不生成无法识别的绑定行。
3. 一个渠道只返回一行；同一渠道的多个令牌聚合在令牌绑定列表中，每个缓存键（即每条绑定）独立一条记录，同一令牌在不同模型/分组上下文的绑定分别展示。
4. 同一渠道内令牌按 token_id 升序、同令牌按键后缀升序排列，渠道按渠道名称升序排列。缓存键必须解析出 token_id，缓存值提供渠道 ID；无法解析 token_id、渠道 ID 非法或关联模型不存在时按第 2、3 条处理。
5. 令牌名称为空时，按 `-（令牌 ID）` 格式显示，保留令牌 ID 作为可识别兜底值。
6. 规则未启用规则名、模型名和分组名时，缓存键可以只包含 token_id；该单段键仍属于有效绑定。
7. 为保证缓存键可逆解析，进入明细的规则只能声明 `context_int/token_id` 键源；规则声明其他键源时，即使同时声明 `context_int/token_id`，其缓存条目也应忽略。
8. 缓存键解析应与现有键构造规则保持可逆。规则名、模型名或分组值包含冒号时，不能因此丢弃有效绑定。
9. 单条清除仅删除目标缓存键对应的绑定（正向缓存、反向占用索引与最近绑定记录），同令牌其他模型、同渠道其他令牌的绑定保持不变；清除请求须确认后执行，接口以明细返回的键后缀精确定位。

#### 4.2.5 交互逻辑

- 加载状态显示加载中提示。
- 没有有效绑定时显示空状态提示。
- 接口请求失败时显示错误提示，用户可关闭弹窗后重新点击入口重试。
- 令牌绑定列表的逐行格式、渠道聚合和排序遵循第 4.2.4 节。
- 点击绑定行清除按钮先弹出确认弹窗，展示令牌名称、令牌 ID、模型与渠道；确认后发起清除请求，取消则直接返回明细弹窗。
- 清除成功后明细列表刷新，被清除的绑定行消失，同令牌其他模型与同渠道其他令牌的行保留；清除失败时提示错误，列表保持原状。

#### 4.2.6 权限要求

本页面权限参见第 2 章，仅根管理员可访问。页面无特殊字段级权限差异。

## 6. 数据状态定义

绑定明细按普通列表处理，定义列表加载、列表展示、空列表、加载失败、清除中和清除失败六种状态：

| 状态 | 页面表现 |
|---|---|
| 加载中 | 弹窗内显示加载提示 |
| 有数据 | 按渠道展示令牌绑定列表与行内清除按钮 |
| 无数据 | 弹窗内显示空状态提示 |
| 加载失败 | 弹窗内显示错误提示，关闭后可重新打开加载 |
| 清除中 | 确认弹窗的确认按钮禁用，防止重复提交 |
| 清除失败 | 显示错误提示，明细列表保持原状 |

## 7. 集成和依赖

| 依赖模块 | 依赖方向 | 数据类型 | 用途 |
|---|---|---|---|
| 渠道亲和性缓存服务 | 本 Feature 主动引用 | 缓存键、渠道 ID | 获取有效缓存绑定并按单条键清除 |
| 渠道模型 | 本 Feature 主动引用 | 渠道 ID、渠道名称 | 展示渠道名称 |

本 Feature 无外部系统依赖、无数据库结构变更、无新增定时任务。

### 7.1 绑定明细接口契约

绑定明细接口为 `GET /api/option/channel_affinity_bindings`，仅根管理员可访问。接口成功时返回统一响应结构，`data` 为渠道聚合数组：

```json
{
  "success": true,
  "message": "",
  "data": [
    {
      "channel_id": 1,
      "channel_name": "主渠道",
      "tokens": [
        {
          "token_id": 101,
          "token_name": "生产令牌",
          "model_name": "gpt-4",
          "key_suffix": "ruleA:gpt-4:101"
        }
      ]
    }
  ]
}
```

接口在无有效绑定时返回空数组。非根管理员访问返回无权限错误，不返回绑定数据；缓存读取或模型查询失败时返回错误响应，页面显示第 4.2.5 节定义的错误提示。

### 7.2 单条绑定清除接口契约

单条绑定清除接口为 `DELETE /api/option/channel_affinity_bindings`，携带查询参数 `key_suffix`（明细接口返回的缓存键后缀原值，须以 token_id 结尾），仅根管理员可访问。参数校验失败返回 HTTP 400；成功时返回：

```json
{
  "success": true,
  "message": "",
  "data": { "deleted": 1 }
}
```

`deleted` 为实际删除的绑定数，键不存在时为 0。删除范围覆盖该键的正向缓存、反向占用索引与最近绑定记录，同令牌其他模型、同渠道其他令牌的绑定不受影响。全量清空与按规则清空沿用 `DELETE /api/option/channel_affinity_cache` 的既有 `all`、`rule_name` 参数。

## 8. 附录

### 8.1 验收标准

1. 根管理员可以在渠道亲和性设置页看到可点击的缓存条目数量。
2. 点击数量后可以打开绑定明细弹窗。
3. 弹窗展示渠道名称和对应令牌名称。
4. 一个渠道绑定多个令牌时只显示一个渠道行，并按第 4.2.4 节规则在令牌绑定列表中逐行展示。
5. 渠道和令牌排序符合第 4.2.4 节规则。
6. 无有效绑定时显示空状态，接口失败时显示错误提示。
7. 非根管理员无法通过接口获取绑定明细。
8. 每条绑定行提供清除按钮，点击后先确认；确认后仅该条绑定被删除，同令牌其他模型、同渠道其他令牌的绑定行保持不变。
9. 清除成功后明细列表与设置页缓存统计刷新；清除失败或非法参数（`key_suffix` 缺失、不以 token_id 结尾）时返回 400 并提示错误，列表不变。

### 8.2 术语说明

| 术语 | 说明 |
|---|---|
| 渠道亲和性缓存 | 根据请求中的亲和性键复用上次成功渠道的内存或 Redis 缓存 |
| token_id | 系统令牌记录的唯一 ID |
| 绑定 | 一个亲和性键当前指向一个渠道的关系 |

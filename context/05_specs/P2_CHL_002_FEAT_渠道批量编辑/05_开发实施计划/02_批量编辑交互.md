# 渠道批量编辑 · 批量编辑交互 实现计划

> **目标：** 在渠道列表页批量工具栏中新增「批量编辑」入口，实现批量编辑抽屉（分区表单、空即跳过、前端校验）、确认弹窗（影响范围与生效字段摘要）与提交链路（成功刷新列表并清除勾选、失败在抽屉内展示失败渠道明细）。
> **架构：** 沿用 channels feature 的现有组织：API 函数收在 `api.ts`，可复用业务动作收在 `lib/channel-actions.ts`，表单校验与提交载荷构造抽成 `lib/channel-batch-edit.ts` 纯函数（可单测），抽屉组件独立成文件并由批量工具栏就地渲染（`selectedIds` 只存在于表格上下文中，不抬升进 Provider）。
> **技术栈：** React 19、TypeScript、TanStack Query、sonner toast、react-i18next、shadcn 风格组件（`@/components/ui/*`，基于 @base-ui/react + Tailwind CSS 4）。表单字段全部非必填且无跨字段依赖，用本地 state + `channel-batch-edit.ts` 纯函数校验，不接入 react-hook-form/zod。

  - 校验规则与错误文案（与后端 T3 同口径，§4.2.2）：
    - `ids.length === 0` → `No channels selected`
    - `ids.length > MAX_BATCH_EDIT_CHANNELS` → `The number of selected channels exceeds the limit of 200. Please split the operation.`
    - group trim 非空且长度 > 64 → `Group must be less than 64 characters`
    - group trim 非空且按 `,` 拆分后存在 trim 为空的段 → `Group format error`
    - tag trim 非空且长度 > 191 → `Tag must be less than 191 characters`
    - remark trim 非空且长度 > 255 → `Remark must be less than 255 characters`
    - test_model trim 非空且长度 > 255 → `Test model must be less than 255 characters`
    - models trim 非空且按 `,` 拆分后存在 trim 为空的段 → `Model list format error`

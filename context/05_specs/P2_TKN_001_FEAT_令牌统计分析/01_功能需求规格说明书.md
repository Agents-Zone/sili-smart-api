# 令牌统计分析 功能需求规格说明书

## 文档信息

- 基线 Feature：无
- 变更组：无
- 变更根节点：无
- 历史基线链：无

## 1. 概述

### 1.1 功能背景

数据看板当前提供模型调用分析、调用分流、用户统计三张统计表，分别按模型、节点分流、用户维度聚合消费数据。运营中定位异常消费、核对单个接入方用量时，常需下探到具体 API Key（系统内对应令牌 token）级别；现有用户统计只能到用户维度，用户持有多个令牌时无法区分是哪一个 key 产生消耗。

底层 `quota_data` 统计表已按小时粒度记录 `token_id` 字段，按令牌维度聚合只缺查询接口与前端展示，数据链路天然具备。

### 1.2 本功能业务目标

1. 管理员在数据看板新增的令牌统计页签中，可查看全站按 API Key（令牌）维度聚合的消费统计。
2. 统计内容与用户统计一致：消费金额排行（柱状图）与消费趋势（面积图），金额按系统汇率换算展示。
3. 图表维度标识展示令牌名称，令牌已删除或名称缺失时回退显示 `#令牌ID`，保证历史数据仍可读。

### 1.3 功能范围

本 Feature 新增一个看板 section 及配套查询接口，仅提供只读统计展示。不修改既有四个 section，不新增导出、下钻、令牌管理操作。数据采集链路（quota_data 写入）为既有能力，不在本 Feature 范围内。

## 3. 页面与功能总览

### 3.1 页面清单

## 4. 页面功能详细说明

### 4.1 页面一：令牌统计页签

#### 4.1.1 页面概述

页面形式为数据看板内嵌 section。职责是以 API Key（令牌）为分组维度，展示选定时间范围内的消费金额排行与消费趋势。图表配置、金额格式化、主题适配均复用用户统计的既有交互。

#### 4.1.2 涉及字段

**A. 查询字段（筛选条件）**

| 字段名称 | 字段类型 | 数据来源 | 默认值 | 业务含义 |
|---|---|---|---|---|
| 时间范围 | 预设选项卡 | 系统预设（1天/7天/14天/29天） | 随初始粒度确定（小时→1天，天→7天，周→30天） | 统计数据的滚动时间窗口 |
| 时间粒度 | 预设选项卡 | 系统预设（小时/天/周） | 用户本地保存的粒度偏好；无保存偏好时为小时 | 趋势图横轴的聚合粒度 |
| Top 数量 | 预设选项卡 | 系统预设（5/10/20/50） | 10 | 排行与趋势展示的令牌数量上限 |

筛选字段的取值、联动与持久化沿用用户统计现有行为：粒度偏好与用户统计共享同一本地存储；切换时间粒度时时间范围重置为该粒度默认天数，粒度选择写入本地存储。

**B. 显示字段（图表维度与指标）**

| 字段名称 | 字段类型 | 数据来源 | 获取时机 | 业务含义 |
|---|---|---|---|---|
| 令牌标识 | 文本（维度轴/图例） | 令牌名称关联 token_id | 图表渲染时 | 令牌名称；名称缺失或令牌已删除时显示 `#令牌ID`（如 `#101`）；token_id 为 0 时显示「无令牌消费」 |
| 消费金额 | 数字（指标轴） | quota 聚合值按系统汇率换算 | 图表渲染时 | 该令牌在时间窗口内的消费金额合计 |
| 时间点 | 文本（维度轴） | created_at 按粒度归一 | 图表渲染时 | 趋势图横轴时间标签 |

#### 4.1.3 功能与按钮

**用户可操作功能：**

- **切换时间范围**
  - 触发按钮：时间范围选项卡
  - 按钮级别：页面级
  - 按钮位置：页面顶部筛选栏
  - 触发方式：点击选项卡
  - 权限要求：管理员
  - 功能说明：按所选天数更新滚动窗口并重新加载数据，行为同用户统计。

- **切换时间粒度**
  - 触发按钮：粒度选项卡（小时/天/周）
  - 按钮级别：页面级
  - 按钮位置：页面顶部筛选栏
  - 触发方式：点击选项卡
  - 权限要求：管理员
  - 功能说明：更新趋势图横轴粒度，同时将时间范围重置为该粒度的默认天数，选择持久化到本地存储。

- **切换 Top 数量**
  - 触发按钮：Top 选项卡（5/10/20/50）
  - 按钮级别：页面级
  - 按钮位置：页面顶部筛选栏
  - 触发方式：点击选项卡
  - 权限要求：管理员
  - 功能说明：调整排行与趋势图纳入的令牌数量上限，重新计算聚合后刷新图表，不重新请求接口。

- **令牌消费排行展示**
  - 触发方式：页面加载或筛选变更后自动渲染
  - 权限要求：管理员
  - 功能说明：水平柱状图，按消费金额降序展示 Top N 令牌，柱末显示金额标签，图题副文本显示 Top N 合计金额；无数据时显示空状态图题。

- **令牌消费趋势展示**
  - 触发方式：页面加载或筛选变更后自动渲染
  - 权限要求：管理员
  - 功能说明：面积图，横轴为时间点、纵轴为消费金额，每个 Top N 令牌一条系列；图例单选模式，悬浮显示该时间点金额；无数据时显示空状态图题。

**前端自动流程：**

- **自动加载**
  - 触发时机：进入令牌统计页签时
  - 说明：按当前筛选条件请求聚合数据，请求期间显示加载指示与图表骨架，完成后渲染图表；数据按时间窗口缓存（staleTime 与用户统计一致）。

#### 4.1.4 业务规则

- **规则1：聚合维度**
  - 规则描述：统计数据按 token_id 分组，聚合 count、quota、token_used，时间窗口按查询时间范围过滤。
  - 触发条件：每次数据查询。
  - 约束说明：排行与趋势均基于同一份聚合结果，前端仅按 Top 数量截取。

- **规则2：令牌名称关联与回退**
  - 规则描述：接口聚合时关联令牌表按 token_id 取名称；名称为空、令牌已被删除时，标识回退为 `#token_id`；token_id 为 0 的记录（无令牌消费，如渠道模型测试）标识展示为「无令牌消费」，聚合数值照常计入。
  - 触发条件：返回数据中存在名称缺失或 token_id 为 0 的记录。
  - 约束说明：回退标识仅影响展示，聚合数值照常计入。

- **规则3：时间跨度限制**
  - 规则描述：查询时间跨度上限与既有看板数据接口一致；超出时接口返回失败信息。
  - 触发条件：时间范围超过预设上限（29 天预设最大跨度）。
  - 约束说明：预设选项卡组合下不会触发，仅保护异常入参。

#### 4.1.5 交互逻辑

- 图表主题跟随系统深浅色切换，行为同用户统计。
- 图例与悬浮提示的金额格式化沿用看板货币显示配置。
- 无数据时图表显示"暂无数据"图题，筛选栏保持可用。

## 5. 非页面功能详细说明

### 5.1 令牌维度消费数据查询接口

#### 5.1.1 功能概述

**触发方式**：API 调用
**触发时机**：管理员进入令牌统计页签或变更筛选条件时
**功能职责**：按 token_id 分组聚合 quota_data，返回时间窗口内各令牌的小时级聚合记录，供前端计算排行与趋势。

#### 5.1.2 处理流程

1. 接收 start_timestamp、end_timestamp 参数并校验（非法或跨度超限时返回错误）。
2. 查询 quota_data 表：按 token_id、created_at 分组，聚合 count、quota、token_used。
3. 关联令牌表补全令牌名称，名称缺失的记录置空由前端回退。
4. 返回聚合记录列表。

#### 5.1.3 涉及数据

| 数据项 | 数据来源 | 数据用途 | 说明 |
|---|---|---|---|
| quota_data 聚合记录 | quota_data 表 | 排行与趋势计算 | 既有统计表，含 token_id 字段 |
| 令牌名称 | 令牌表（tokens） | 展示标识 | 按 token_id 关联查询 |

#### 5.1.4 业务规则

- 接口挂管理员认证中间件，非管理员请求直接拒绝。
- 聚合查询复用 quota_data 既有索引与分组方式，仅分组字段由 username 变为 token_id。

#### 5.1.5 异常处理

| 异常场景 | 处理方式 | 错误提示/日志 |
|---|---|---|
| 时间参数非法或跨度超限 | 返回失败响应 | 提示时间范围不合法 |
| 数据库查询失败 | 返回失败响应并记录后端日志 | 通用错误信息 |

#### 5.1.6 与其他功能的关联

- **上游依赖**：quota_data 采集任务（既有，按小时聚合写入）
- **下游影响**：无，纯只读查询

## 6. 数据状态定义

本功能为只读统计展示，无自有数据状态与状态流转。令牌本身的启停、删除状态由令牌管理功能定义；本功能仅消费其名称做展示，删除令牌不改变历史统计数值。

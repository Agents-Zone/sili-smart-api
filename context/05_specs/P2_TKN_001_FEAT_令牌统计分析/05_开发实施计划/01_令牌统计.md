# 令牌统计 实现计划

> **目标：** 数据看板新增管理员可见的「令牌统计」页签，按 API Key（令牌）维度展示消费排行（水平柱状图）与消费趋势（面积图），配套一个按 token_id 聚合 quota_data 的只读查询接口。
> **架构：** 后端沿既有 `GetQuotaDataGroupByUser` 形态新增按 token_id 分组的聚合查询，复用 `fillFlowTokenNames` 的名称关联模式（软删除留空回退）；前端沿用户统计（`UserCharts` + `processUserChartData`）的模式新建令牌图表组件，经 section-registry 注册为 adminOnly 页签。零数据库迁移。
> **技术栈：** Go 1.22+（Gin + GORM v2）、React 19 + TypeScript、TanStack Query、VChart（@visactor/react-vchart）、i18next。

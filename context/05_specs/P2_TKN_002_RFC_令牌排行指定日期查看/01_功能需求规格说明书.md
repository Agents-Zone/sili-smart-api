## 1. 概述

### 1.1 功能背景

> [修改] 补充：基线交付的滚动窗口无法定位具体自然日。

基线功能已提供按令牌维度的用量排行与趋势，时间窗口为滚动预设（1 天/7 天/14 天/29 天）。其中"1 天"为过去 24 小时滚动至当前时刻，跨两个自然日且随查看时刻变化，运营核对"某一天消耗了什么"时无法得到稳定口径：既看不了完整的历史某一天，也看不了纯当日（00:00 起）的数据。定位某日异常消耗、按日对账需要按自然日固定窗口的查看能力。

### 1.2 本功能业务目标

1. 管理员在令牌统计页签可直接指定某个自然日（如 2026-11-03），查看该日的令牌用量排行，窗口固定为该日 00:00:00 起的完整自然日。
2. 指定日期模式下，令牌用量趋势按小时展示该日 24 小时走势，与排行共用同一份该日数据。
3. 指定日期与既有滚动预设互斥共存：任一时刻只有一种窗口生效，切换不丢失另一侧的最近选择习惯（预设选择随页签状态保留，粒度偏好沿用本地持久化）。
4. 查询接口与数据链路零改动，自然日窗口即普通时间窗口，纯前端筛选扩展。

### 1.3 功能范围

> [修改] 范围说明补充指定日期模式边界。

本变更仅扩展令牌统计页签的时间筛选能力，新增指定日期模式。仅提供只读统计展示；不改动滚动预设、Top 数量、图表渲染、缓存与权限的既有行为；不新增导出、下钻、自定义起止日期区间。用户统计页签不在本变更范围内。

## 2. 角色与权限矩阵

## 4. 页面功能详细说明

### 4.1 页面 1：令牌统计页签

#### 4.1.1 页面概述

> [修改] 筛选栏新增日期选择器；页面职责扩展为支持指定自然日窗口。

**页面形式：** 数据看板内嵌 section（同基线）

**页面职责：** 以 API Key（令牌）为分组维度，展示选定时间范围内的令牌用量排行与用量趋势。时间范围支持两种互斥模式：滚动预设（1/7/14/29 天）与指定日期（某个自然日）。指定日期模式下趋势固定按小时粒度。

**页面布局示意：**

```text
┌────────────────────────────────────────────────────────────────────┐
│ 数据看板                                                           │
├────────────────────────────────────────────────────────────────────┤
│ [令牌统计] [模型调用分析] [调用分流] [用户统计]                        │ ← 页签导航
├────────────────────────────────────────────────────────────────────┤
│ [1天][7天][14天][29天] [📅 2026-11-03 ✕]  [小时][天][周]  Top [5][10][20][50] ◐ │
│   ↑ 预设（指定日期生效时取消高亮）  ↑ 日期选择器        ↑ 指定日期时禁用       │
├────────────────────────────────────────────────────────────────────┤
│ ┌────────────────────────────────────────────────────────────────┐ │
│ │ ▣ 令牌用量排行                        2026-11-03 · 合计: 3.21 M  │ │
│ │  key-prod-01   ████████████████          1.92 M                 │ │
│ │  ...                                                           │ │
│ └────────────────────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────────────────────────────┐ │
│ │ ▣ 令牌用量趋势                  2026-11-03 · 合计: 3.21 M        │ │
│ │  （横轴为该日 00:00 ~ 23:00 共 24 个小时点）                       │ │
│ └────────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────┘
```

#### 4.1.2 涉及字段

> [修改] 查询字段新增"指定日期"；"时间范围"默认值校正周粒度口径（29 天）并补充互斥关系。显示字段无变化。

**A. 查询字段（筛选条件）**

| 字段名称 | 字段类型 | 数据来源 | 默认值 | 业务含义 |
|---|---|---|---|---|
| 时间范围 | 预设选项卡 | 系统预设（1天/7天/14天/29天） | 随初始粒度确定（小时→1天，天→7天，周→29天） | 统计数据的滚动时间窗口；指定日期生效时取消高亮并暂停生效 |
| **[新增]** 指定日期 | 日期选择器 | 用户选择（yyyy-MM-dd） | 空（未启用指定日期模式） | 指定某个自然日作为统计窗口；仅可选今天及历史日期，未来日期禁用 |
| 时间粒度 | 预设选项卡 | 系统预设（小时/天/周） | 用户本地保存的粒度偏好；无保存偏好时为小时 | 趋势图横轴的聚合粒度；指定日期生效时禁用（固定按小时） |
| Top 数量 | 预设选项卡 | 系统预设（5/10/20/50） | 10 | 排行与趋势展示的令牌数量上限；两种模式下行为一致 |

**B. 显示字段（图表维度与指标）**

> **[无变化]** 令牌标识、令牌用量、时间点三个显示字段与基线一致。指定日期模式下时间点按小时归一展示。

#### 4.1.3 功能与按钮

> [修改] 新增"指定日期筛选"功能；既有"切换时间范围""切换时间粒度"补充互斥行为；其余功能无变化。

**用户可操作功能：**

- **[新增] 指定日期筛选**
  - 触发按钮：筛选栏日期选择器
  - 按钮级别：页面级
  - 按钮位置：页面顶部筛选栏（时间范围预设与时间粒度之间）
  - 触发方式：点击打开日期面板选择日期；选中后显示日期标签与清除按钮（✕）
  - 权限要求：管理员
  - 功能说明：选择某个自然日后，统计窗口切换为该日（历史日为 00:00:00~23:59:59，今天为 00:00:00~当前时刻），重新加载排行与趋势；与滚动预设的互斥行为见规则 5，粒度禁用行为见规则 6。点击 ✕ 清除日期，回到此前选中的滚动预设并恢复粒度可用。

- **[修改] 切换时间范围**
  - 功能说明补充：按所选天数更新滚动窗口并重新加载数据；与指定日期的互斥行为见规则 5。

- **[修改] 切换时间粒度**
  - 功能说明补充：指定日期生效时粒度选项卡禁用（置灰不可点），不影响已保存的粒度偏好；清除指定日期后恢复可用。

- 切换 Top 数量：**[无变化]**，两种模式下均为前端截取，不重新请求接口。

- 令牌用量排行展示、令牌用量趋势展示：**[无变化]**，渲染行为同基线；指定日期模式下数据源为该日聚合结果，趋势横轴为该日 24 个小时点。

**前端自动流程：**

- **自动加载**
  - 触发时机：进入令牌统计页签或筛选变更（含指定日期变化）时
  - 说明：按当前生效窗口请求聚合数据，请求期间显示加载指示与骨架；数据按窗口缓存（指定日期模式的缓存键含所选日期）。

#### 4.1.4 业务规则

> [修改] 新增规则 4~6；规则 1~3（聚合维度、令牌名称关联与回退、时间跨度限制）无变化。

- **[新增] 规则4：自然日窗口**
  - 规则描述：指定历史日期 D 时，统计窗口为 D 日 00:00:00 至 23:59:59（本地时区）；指定今天时，窗口为今日 00:00:00 至当前时刻。
  - 触发条件：用户在日期选择器中选定日期。
  - 约束说明：自然日窗口为普通时间窗口，跨度恒不超过 29 天上限，复用既有接口与时间跨度校验，无接口改动。

- **[新增] 规则5：指定日期与预设互斥**
  - 规则描述：指定日期与时间范围预设同一时刻仅一种生效。指定日期生效时预设取消高亮；点选任一预设即清除指定日期；清除指定日期后回到此前预设。两模式的最近选择均随页签状态保留。
  - 触发条件：任一筛选入口发生切换。
  - 约束说明：互斥仅作用于时间窗口，Top 数量在两模式间共用。

- **[新增] 规则6：指定日期模式下的粒度行为**
  - 规则描述：指定日期生效时趋势图固定按小时粒度展示该日 24 小时走势，粒度选项卡禁用；排行图不受粒度影响。
  - 触发条件：指定日期生效期间。
  - 约束说明：禁用不改变已保存的粒度偏好，退出指定日期模式后按原偏好恢复。

#### 4.1.5 交互逻辑

> [修改] 新增日期选择器交互与副标题日期展示；既有主题跟随、数值格式化、高度自适应、空状态行为无变化。

- **[新增]** 日期选择器中今天及历史日期可选，未来日期禁用；所选日期以 yyyy-MM-dd 显示在筛选栏标签中，标签附清除按钮。
- **[新增]** 排行与趋势图题副文本展示当前统计窗口：指定日期模式显示所选日期（如 `2026-11-03 · 合计: 3.21 M`）；预设模式显示窗口起止日期（如 `2026-10-08 ~ 2026-11-06 · 合计: 12.34 M`）。
- **[新增]** 指定日期为今天时，数据截至当前时刻，副标题仍显示今日日期；该日后续新增消耗在下次查询时体现。
- **[新增]** 指定日期模式下的粒度选项卡置灰；悬浮提示"指定日期时按小时展示"。
- 图表主题跟随系统深浅色切换、数值格式化（M 单位两位小数）、排行图高度随 Top 数量自适应、无数据空状态：**[无变化]**，同基线。

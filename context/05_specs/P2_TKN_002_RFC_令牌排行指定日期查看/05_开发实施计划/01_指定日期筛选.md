# 令牌排行指定日期筛选 实现计划

> **目标：** 令牌统计页签在滚动预设之外新增指定日期模式：管理员选定某个自然日后，排行与趋势按该日数据展示，趋势固定按小时粒度（24 个小时点），与滚动预设互斥共存。
> **架构：** 纯前端筛选扩展，接口与数据链路零改动。自然日窗口由新的纯函数计算（历史日为 D 00:00:00~23:59:59，今天为今日 00:00:00~当前时刻），映射为既有 `GET /api/data/tokens` 的普通参数取值；24 小时趋势轴通过共享图表构造器 `buildTopNChartSpecs` 的可选显式时间点参数实现；日期选择器复用既有 `DatePicker` 组件并补清除能力；互斥状态落在既有 `TopNChartsFilters`（由 dashboard 父组件持有，页签切换天然保留）。
> **技术栈：** React 19 + TypeScript、TanStack Query、react-day-picker（经既有 DatePicker/Calendar 封装）、dayjs、i18next、bun test（node:test 风格）。

  - 签名：
    - `export function resolveDayWindow(selectedDate: string, now: Date = new Date()): { start_timestamp: number; end_timestamp: number } | null`
    - `export function buildDayHourPoints(selectedDate: string): string[]`
  - 关键逻辑：
    - `resolveDayWindow` 输入校验：正则 `/^\d{4}-\d{2}-\d{2}$/` 不匹配、`dayjs(selectedDate)` 解析后 `format('YYYY-MM-DD')` 与输入不一致（防 `2026-02-31` 溢出滚动）、或解析日 `startOf('day')` 晚于 `now` 的 `startOf('day')`（未来日期）时返回 `null`。
    - 指定今天（解析日与 `now` 同日，本地时区）：`start_timestamp` = 今日 00:00:00 秒级时间戳，`end_timestamp` = `Math.floor(now.getTime() / 1000)`（数据截至当前时刻）。
    - 指定历史日 D：`start_timestamp` = D 00:00:00 秒级时间戳，`end_timestamp` = D 23:59:59 秒级时间戳（`dayjs(D).endOf('day').unix()`）。
    - `buildDayHourPoints`：同一校验失败返回 `[]`；否则返回 D 日 24 个小时点标签，第 h 项为 `formatChartTime(startSec + h * 3600, 'hour')`（即 `MM-DD HH:00`，00:00 ~ 23:00）。
  - 依赖：`@/lib/dayjs` dayjs（既有，date-only 短串按本地时区午夜解析）、`@/lib/time` `formatChartTime`（既有）。返回秒级时间戳与 `useTopNTimeRange` 及 `getTokenQuotaDataByTokens` 参数口径一致。

  **验收锚点：**
  - 核心断言（`use-topn-time-range.test.ts`，固定 `now = new Date('2026-11-06T10:30:45')` 注入）：
    - 历史日：`resolveDayWindow('2026-11-03', now)` 返回 `start_timestamp === dayjs('2026-11-03').startOf('day').unix()` 且 `end_timestamp === start_timestamp + 86399`。
    - 今天：`resolveDayWindow('2026-11-06', now)` 返回 `start_timestamp === dayjs('2026-11-06').startOf('day').unix()` 且 `end_timestamp === Math.floor(now.getTime() / 1000)`。
    - 未来日期：`resolveDayWindow('2026-11-07', now)` 返回 `null`。
    - 非法输入：`resolveDayWindow('2026-02-31', now)`、`resolveDayWindow('', now)`、`resolveDayWindow('not-a-date', now)` 均返回 `null`。
    - 小时点：`buildDayHourPoints('2026-11-03')` 长度 24，`[0] === formatChartTime(dayjs('2026-11-03').startOf('day').unix(), 'hour')`，`[23] === '11-03 23:00'`；`buildDayHourPoints('bad')` 返回 `[]`。

# 独占引擎 实现计划

> **目标：** 在渠道亲和性 miss 且规则启用 exclusive_bind 时，按渠道独占语义完成选路决策、原子占位、绑定登记/迁移/回滚，新增反向占用索引与最近绑定记录两个运行时命名空间。
> **架构：** 新建 `service/channel_affinity_exclusive.go` 承载独占运行时核心（存储、决策、占位），决策为纯函数便于表驱动测试；存储用 cachex.HybridCache 双命名空间（Redis 优先、内存回退），进程内按亲和键分段锁实现先到先得；`service/channel_affinity.go` 的现有函数做接入点扩展。model 层新增候选集导出函数供独占筛空闲渠道。
> **技术栈：** Go 1.22+、Gin、pkg/cachex（HybridCache + JSONCodec）、samber/hot、testify（require/assert）

### 新建文件
- `service/channel_affinity_exclusive.go` — 独占绑定运行时核心：反向占用索引与最近绑定记录存储、绑定决策纯函数、原子占位（按亲和键分段锁）
- `service/channel_affinity_exclusive_test.go` — 上者的表驱动测试（含并发先到先得）

- `model/channel_candidates_test.go` — 候选集函数测试

- `setting/operation_setting/channel_affinity_setting.go` — ChannelAffinityRule 新增 ExclusiveBind 布尔字段（json: exclusive_bind）
- `service/channel_affinity.go` — channelAffinityMeta 扩展 ExclusiveBind/CacheKeySuffix；GetPreferredChannelByAffinity miss 分支接入独占选路；RecordChannelAffinity 登记反向索引与最近绑定；ClearCurrentChannelAffinityCache 清理反向索引条目
- `middleware/distributor.go` — 无改动：独占占位在 GetPreferredChannelByAffinity 内闭环，现有 preferredChannelID 分支直接消费 found 结果（T4 契约注明）
- `controller/relay.go` — Relay 与 RelayTask 终态失败出口接入独占占位回滚（T5）
